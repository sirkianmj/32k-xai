# Security Policy

## Supported Versions

Currently, only the latest major release of 32k-XAI is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of 32k-XAI seriously. If you believe you have found a security vulnerability, please **do not** report it via public GitHub issues.

Instead, please use GitHub's built-in [Private Vulnerability Reporting](https://github.com/sirkianmj/32k-xai/security/advisories/new) feature. 

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.
